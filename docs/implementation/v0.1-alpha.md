# v0.1-alpha implementation status

## Goal

Prove a traceable single-photo workflow from a clean TypeScript CLI:

```text
explicit RAW + preview pair
  -> sanitized preview
  -> Codex-local review handoff -> semantic intent
  -> deterministic normalized edit plan
  -> Lightroom checkpoint + mutation
  -> read-back reconciliation
  -> disposable session render
```

The alpha stops at `REVIEW_REQUIRED`; it has no automated visual evaluator.

## Scope checklist

- [x] Standalone repository scaffold and MIT/provenance documentation.
- [x] Versioned Zod schemas and state machine.
- [x] Local pair validation, SHA-256 source hashing, and metadata-safe preview generation.
- [x] Mock provider and deterministic intent-to-parameter translator.
- [x] Codex-local provider handoff with schema-validated resume path.
- [x] OpenAI Responses provider behind a provider interface (explicit opt-in only).
- [x] Lightroom MCP adapter contract and mock adapter.
- [x] Durable session manifest/state/event log with atomic writes.
- [x] CLI `edit-one` and `resume` paths with dry-run and explicit apply/cloud flags.
- [x] Unit and mock integration tests.
- [ ] Live Lightroom E2E on a non-critical user test photo.
- [ ] Human visual inspection of the resulting render.

## Explicit non-goals

No culling, clustering, batch orchestration, Style Memory, render evaluation,
automatic acceptance, XMP fallback, preset export stability claim, public
deployment, or automatic spawning of a second Codex process is part of this
alpha. The current Codex session performs the review handoff itself.

## Acceptance boundary

Automated tests prove deterministic contracts and safety behavior only. A live
Lightroom run requires Lightroom Classic and the plugin to be connected; its
visual quality and `.lrtemplate` re-import compatibility remain manual checks.
