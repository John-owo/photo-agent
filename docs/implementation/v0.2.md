# v0.2 closed-loop editing status

Implemented:

- explicit `EVALUATING`, `REFINING`, and `ACCEPTED` states;
- one checkpoint, read-back, render, and evaluation artifact per iteration;
- exact per-iteration evidence links with SHA-256 fingerprints for the plan,
  checkpoint, read-back, backend render, sanitized preview, and evaluator
  result; evaluator failures are recorded as review-required and can never
  become an accepted edit;
- deterministic session previews at
  `renders/iteration-{n}/preview.jpg`, with an explicit preview policy and a
  separate final-export seam that requires negotiated backend support,
  delivery settings, and an explicit destination;
- `edit-one` and `resume` expose time, render, evaluator-call, token, and
  estimated-cost budgets. Exhaustion is recorded as a named
  `REVIEW_REQUIRED` reason and never becomes success. Defaults are 5 minutes,
  one render/evaluator call per allowed iteration, 100,000 evaluator tokens,
  and USD 1.00;
- evaluator rationale and usage accounting in `iteration-report.json`;
- cancellation-aware execution: read-only cancellation ends in `CANCELLED`,
  cancellation after a backend side effect ends in `REVIEW_REQUIRED`, and
  backend lease release is recorded durably;
- bounded iteration count, low-confidence escalation, repeated render/plan stall
  detection, and terminal `ACCEPTED` or `REVIEW_REQUIRED` behavior;
- checkpoint-only rollback metadata without claiming Lightroom true undo;
- v0.1 artifact aliases for backward compatibility;
- local scripted/mock evaluators plus an opt-in `OpenAIEditEvaluator` with a
  schema-validated response. A cloud evaluator is refused unless
  `--allow-cloud-preview` is present, including on `resume`, and receives a new
  sanitized per-iteration JPEG rather than the backend render path.

Automated evidence on 2026-08-12 and 2026-08-31:

- accept on first evaluation;
- refine, re-render, then accept;
- repeated refinement escalates instead of silently retrying;
- cloud evaluation is rejected before the evaluator/backend is called without
  explicit consent, while an allowed fake receives only the sanitized session
  copy;
- full TypeScript, lint, test, and build gates pass (see `WORKLOG.md`).
- read-only and post-mutation cancellation preserve terminal-state integrity,
  durable cancellation evidence, and backend lease-release evidence.

read through `LightroomMcpAdapter`, exported to a generated session directory,
and visually inspected as a valid Lightroom render. The proof made no checkpoint
