# v0.1-alpha 實作狀態

## 目標

透過乾淨的 TypeScript CLI，驗證一條可追蹤的單張照片流程：

```text
明確配對的 RAW + 預覽圖
  -> 清理後的預覽圖
  -> Codex 本機檢查交接 -> semantic intent
  -> deterministic normalized edit plan
  -> Lightroom checkpoint + mutation
  -> read-back reconciliation
  -> 可丟棄的 session render
```

這個 alpha 版本會停在 `REVIEW_REQUIRED`，沒有自動視覺評估器。

## 範圍檢查表

- [x] 獨立 repository scaffold、MIT 授權與 provenance 文件。
- [x] 版本化 Zod schema 與狀態機。
- [x] 本機配對檢查、SHA-256 來源雜湊與 metadata-safe 預覽產生。
- [x] Mock provider 與 deterministic intent-to-parameter translator。
- [x] Codex 本機 provider 交接與 schema 驗證的 resume 路徑。
- [x] OpenAI Responses provider 已放在 provider interface 後方，且只可明確選用。
- [x] Lightroom MCP adapter 契約與 mock adapter。
- [x] 具備 atomic write 的持久化 session manifest/state/event log。
- [x] CLI `edit-one` 與 `resume` 路徑，支援 dry-run 及明確的 apply/cloud 旗標。
- [x] 單元測試與 mock integration tests。
- [ ] 在非關鍵使用者測試照片上執行 Lightroom live E2E。
- [ ] 人工檢查產生的 render。

## 明確不包含

本 alpha 不包含選片、聚類、批次協調、Style Memory、render 評估、自動接受、XMP fallback、preset export 穩定性保證、公開部署，或自動啟動第二個 Codex 程序。目前由同一個 Codex 工作階段執行 review handoff。

## 驗收邊界

自動化測試只證明 deterministic 契約與安全行為。真正的 Lightroom 執行需要 Lightroom Classic 與 plugin 已連線；視覺品質與 `.lrtemplate` 重新匯入相容性仍須人工檢查。
